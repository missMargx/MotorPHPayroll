# MotorPH Employee Payroll System (Java GUI)
Java | GUI - Java Swing | IDE - NetBeans

**Overview**

### The MotorPH Employee Payroll System is a desktop GUI application built with Java Swing that allows employees and payroll staff to manage and view payroll information through an easy-to-use graphical interface.
 ---

**Two Account Types:**
  * Employee Account - View only access
  * Payroll Staff Account - Full processing access
